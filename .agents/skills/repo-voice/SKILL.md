# Repo voice

Comrade's voice is the product: plain answers, cited sources, no engagement
bait. The prose must practice what the tool preaches.

- **No engagement patterns.** Never "Would you like to…?", never "You might
  also…", never "Check out…". State the thing. Then stop.
- **Lefty rhetoric is sincere, not costume.** The tagline works because it's
  a quote, not a threat. Prose stays calmer than the tagline: "reclamation",
  not "repossession". Don't reach for militancy the tagline already earned.
- **No emojis, no corporate README-speak** ("blazingly fast", "seamless",
  "powerful"). If a sentence survives deletion, delete it.
- **Oxford comma, always.**
- **Descriptions survive strangers.** One-liners must carry meaning for
  someone who doesn't know the joke; the README can then have fun.
- Commit messages: active sentences ("Add …", "Fix …", "Wire up …"). The
  initial commit of a repo is titled "initial commit" with a body that
  tells the story.
